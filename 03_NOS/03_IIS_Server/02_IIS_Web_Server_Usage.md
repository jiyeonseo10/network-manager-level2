# IIS Web Server Usage

네트워크관리사 2급 NOS 파트의 **IIS 웹 서버 사용** 내용을 정리한다.

---

## 1. IIS 기능

IIS는 웹 브라우저의 **HTTP Request**에 대해 **HTTP Response**로 HTML을 전송한다.

주요 기능은 다음과 같다.

- HTTP Request에 대해 HTTP Response로 HTML 전송
- HTTP 리디렉션 지원
- HTTP 상태 코드를 통한 오류 관리
- HTTP 로깅 정보 기록 및 관리
- ASP 및 .NET 언어 지원
- SSL 인증서를 등록하여 SSL 보안 지원

IIS 관리자에서는 다음 기능도 확인할 수 있다.

- HTTP 리디렉션
- HTTP 응답 헤더
- ISAPI 및 CGI 지원
- ISAPI 필터
- MIME 형식

```text
IIS
→ HTTP Request / Response
→ HTTP 리디렉션
→ HTTP 상태 코드
→ HTTP 로깅
→ ASP / .NET 지원
→ SSL 지원
```

---

## 2. 웹 사이트 추가

IIS에서는 **웹 사이트 추가** 기능을 이용하여 새로운 웹 사이트 정보를 등록할 수 있다.

웹 사이트 등록 시 주요 설정 항목은 다음과 같다.

- 실제 경로
- 포트 번호
- 호스트 이름

### 실제 경로
웹 사이트의 홈 디렉토리를 지정한다.

### 포트 번호
웹 사이트는 기본적으로 **80번 포트**를 사용하지만 변경할 수 있다.

### 호스트 이름
웹 사이트에 사용할 URL 주소를 입력한다.

```text
웹 사이트 추가
→ 실제 경로 = 홈 디렉토리
→ 기본 포트 = 80
→ 포트 번호 변경 가능
→ 호스트 이름 = URL 주소
```

등록된 웹 사이트는 사이트 목록에서 확인할 수 있으며,
고급 설정을 통해 웹 사이트 주소, 포트 번호, 프로토콜 등의 정보를 확인할 수 있다.

## 3. HTTP 리디렉션

HTTP 리디렉션은 특정 주소로 접속했을 때 다른 페이지로 자동 연결되도록 설정하는 기능이다.

예를 들어 다음 주소로 접속했을 때

```text
www.boanteam.com
```

다음 페이지로 자동 연결되도록 설정할 수 있다.

```text
www.boanteam.com/boan/boan.jsp
```

```text
HTTP 리디렉션
→ 특정 주소로 접속
→ 등록된 다른 페이지로 자동 연결
```

---

## 4. 오류 페이지

웹 페이지에서 오류가 발생했을 때 실제 오류 정보를 그대로 노출하지 않고
별도의 오류 페이지를 등록하여 보여줄 수 있다.

HTTP 상태 코드 값에 따라 오류가 발생하면
웹 브라우저에 전달할 페이지를 등록한다.

```text
오류 페이지
→ HTTP 상태 코드에 따라 오류 처리
→ 오류 정보 노출 방지
→ 별도 오류 페이지 제공
```

---

## 5. 가상 디렉토리

가상 디렉토리는 실제 페이지 경로가 URL에 나타나지 않도록 하여 보안을 향상시키는 기능이다.

실제로 존재하지 않는 디렉토리 이름을 사용하여
웹 페이지나 파일을 등록하고 관리할 수 있다.

가상 디렉토리를 등록할 때 다음 정보를 설정한다.

- 별칭
- 실제 경로

```text
가상 디렉토리
→ 실제 경로를 URL에 노출하지 않음
→ 보안 향상
→ 별칭과 실제 경로 연결
```
