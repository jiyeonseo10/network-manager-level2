# Windows User Account

네트워크관리사 2급 NOS 파트의 **윈도우 서버 사용자 계정과 사용자 프로필** 내용을 정리한다.

---

## 1. 내장형 사용자 계정

Windows Server를 설치하면 기본적으로 `Administrator`와 `Guest` 계정이 생성된다.

### Administrator

- Windows에 반드시 존재해야 하는 계정
- 관리자 권한을 가짐
- 관리자가 삭제할 수 없음

### Guest

- Windows Server에 로그인할 수 있는 계정
- 최소한의 권한만 가짐
- 자동 생성되지만 처음에는 비활성화되어 있음
- 계정 관리에서 활성화해야 사용할 수 있음

```text
Administrator
→ 관리자 권한
→ 삭제 불가

Guest
→ 최소 권한
→ 기본적으로 비활성화
→ 활성화 후 사용
```

---

## 2. 계정 관리

윈도우 제어판에서 계정 관리를 실행할 수 있다.

계정 관리에서는 다음 작업을 할 수 있다.

- 현재 생성된 모든 계정 목록 확인
- 새로운 윈도우 사용자 계정 생성

---

## 3. 새로운 사용자 생성

계정 관리에서 사용자 추가를 이용하면 새로운 윈도우 계정을 생성할 수 있다.

사용자 추가 시 입력하는 정보는 다음과 같다.

- 사용자 이름
- 암호
- 암호 다시 입력
- 암호 힌트

책에서는 암호 정책을 준수하여 **8자 이상**으로 입력한다고 설명한다.

사용자 계정을 생성하면 로컬 계정으로 추가된다.

---

## 4. 계정 유형 변경

사용자 계정에 관리자 권한을 부여하려면 계정 유형 변경을 사용한다.

계정 유형은 표준과 관리자로 구분된다.

| 계정 유형 | 설명 |
|---|---|
| 표준(Standard) | 소프트웨어를 사용할 수 있지만 시스템 보안과 관련된 설정은 변경할 수 없음 |
| 관리자(Administrator) | Windows Server를 관리할 수 있는 모든 권한을 가짐 |

```text
표준
→ 일반적인 소프트웨어 사용 가능
→ 시스템 보안 관련 설정 변경 불가

관리자
→ Windows Server 관리에 필요한 모든 권한
```

---

## 5. 사용자 프로필

사용자 프로필은 Windows 시스템 사용자의 설정 및 데이터를 보관하는 데이터이다.

사용자 프로필에는 다음과 같은 정보가 포함된다.

- 사용자 바탕화면
- 응용 프로그램 이용 정보
- 시스템 설정 정보

네트워크를 통해 사용자 프로필을 제공하면 사용자가 사용하는 환경을 함께 제공할 수 있다.

### 사용자 프로필의 장점

- 원격으로 Windows Server에 접속하여 저장된 사용자 프로필 사용 가능
- 사용자 프로필을 이용하여 항상 일관된 바탕화면 및 설정 사용 가능

---

## 6. 사용자 프로필 종류

### 로컬 사용자 프로필

Windows 시스템에 직접 로그인하는 사용자의 정보이다.

- 사용자 로그인 구성 정보
- 인터넷 환경
- 바탕화면 등의 정보 제공
- 책에서는 다음 위치에 저장한다고 설명한다.

```text
C:\Documents and Settings\사용자ID
```

### 로밍 사용자 프로필

- 사용자 프로필을 Windows Server에 저장
- 사용자가 어떤 Windows 클라이언트를 사용하더라도 같은 환경 제공

```text
로밍 사용자 프로필
→ 서버에 저장
→ 다른 Windows 클라이언트에서도 같은 환경
```

### 강제 사용자 프로필

- Windows 시스템의 바탕화면 및 시스템 환경을 변경할 수 없음
- 사용자에게 공통된 환경 제공

```text
강제 사용자 프로필
→ 환경 변경 불가
→ 공통된 환경 제공
```

## 7. 시험 직전 암기

```text
Administrator
→ 관리자 권한
→ 삭제 불가

Guest
→ 최소 권한
→ 기본적으로 비활성화

계정 유형
→ 표준 / 관리자

표준
→ 시스템 보안 관련 설정 변경 불가

관리자
→ Windows Server 관리 전체 권한

사용자 프로필
→ 사용자 설정 및 데이터 저장

로컬 사용자 프로필
→ 해당 Windows 시스템 사용자 정보
→ C:\Documents and Settings\사용자ID

로밍 사용자 프로필
→ Windows Server에 저장
→ 다른 Windows 클라이언트에서도 동일한 환경

강제 사용자 프로필
→ 바탕화면 및 시스템 환경 변경 불가
→ 공통된 환경 제공
```
