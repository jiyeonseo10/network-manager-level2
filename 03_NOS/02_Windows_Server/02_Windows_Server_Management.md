# Windows Server Management

네트워크관리사 2급 NOS 파트의 **윈도우 서버 관리와 이벤트 뷰** 내용을 정리한다.

---

## 1. 컴퓨터 관리

컴퓨터 관리는 개인용 PC의 Windows와 Windows Server에 모두 존재하는 관리 프로그램으로, Windows 시스템을 관리하기 위한 대부분의 기능을 포함한다.

### 컴퓨터 관리 주요 기능

| 기능 | 설명 |
|---|---|
| 작업 스케줄러 | 정해진 시간에 작업을 수행 |
| 이벤트 뷰어 | Windows에서 발생한 로그 정보를 기록하고 확인 |
| 공유 폴더 | 폴더 공유 설정 및 해제, 세션 관리 |
| 로컬 사용자 및 그룹 | 기본 사용자 및 그룹 목록 확인, 새로운 그룹 생성 |
| 성능 | CPU, 메모리, 디스크 사용률 모니터링 |
| 장치 관리자 | CPU, Memory, Bus, Disk, NIC 카드, 마우스, 키보드, CD-ROM 등의 하드웨어 관리 |
| 저장소 | 파일 시스템 정보와 디스크 할당 정보 확인 |
| 서비스 및 응용 프로그램 | 등록된 서비스와 설치되어 있는 프로그램 관리 |

### 핵심 정리

```text
작업 스케줄러
→ 정해진 시간에 작업 수행

이벤트 뷰어
→ 로그 정보 기록 및 확인

공유 폴더
→ 공유 설정 / 해제
→ 세션 관리

로컬 사용자 및 그룹
→ 사용자 / 그룹 관리

성능
→ CPU / 메모리 / 디스크 사용률 모니터링

장치 관리자
→ 하드웨어 관리

저장소
→ 파일 시스템 / 디스크 할당 정보

서비스 및 응용 프로그램
→ 서비스 / 설치 프로그램 관리
```

---

## 2. 이벤트 뷰

**이벤트 뷰(Event View)** 는 Windows 시스템 사용 중 발생하는 각종 이벤트 정보를 확인할 수 있는 프로그램이다.

이벤트는 다음과 같이 분류된다.

- 응용 프로그램
- 보안
- 시스템

이벤트 뷰에는 다음과 같은 로그가 기록된다.

- 애플리케이션 사용
- 시스템 부팅 및 종료
- 사용자 로그인
- 사용자 계정 생성

사용자 계정을 생성한 경우 해당 로그 정보가 **보안 이벤트**에 기록될 수 있다.

### 핵심 정리

```text
Event View
→ Windows에서 발생한 이벤트 정보 확인

이벤트 분류
→ 응용 프로그램
→ 보안
→ 시스템

기록되는 로그
→ 애플리케이션 사용
→ 시스템 부팅 / 종료
→ 사용자 로그인
→ 사용자 계정 생성
```

---

## 3. 로그 속성 설정

이벤트 정보는 **덮어쓰기 방식**으로 관리된다.

최대 로그 크기를 초과하여 새로운 이벤트가 발생하면 기존 이벤트 정보를 덮어쓴다.

로그 속성 설정에서 다음 항목을 설정할 수 있다.

- 이벤트 로그 파일명
- 최대 로그 크기
- 덮어쓰기 옵션

### 핵심 정리

```text
이벤트 로그
→ 덮어쓰기 방식으로 관리

설정 가능 항목
→ 로그 파일명
→ 최대 로그 크기
→ 덮어쓰기 옵션
```
