# Security Policy

네트워크관리사 2급 NOS 파트의 **윈도우 서버 보안 정책** 내용을 정리한다.

---

## 1. 보안 정책 개요

윈도우 서버의 보안 정책은 **로컬 보안 정책** 프로그램을 통해 관리할 수 있다.

로컬 보안 정책에서는 다음과 같은 항목을 설정할 수 있다.

- 암호 정책
- 계정 잠금 정책
- 로컬 정책
- 윈도우 방화벽 정책

```text
로컬 보안 정책
→ 암호 정책
→ 계정 잠금 정책
→ 로컬 정책
→ 윈도우 방화벽 정책
```

---

## 2. 암호 정책 관리

계정 정책에서 암호 정책을 선택하면 사용자 암호에 대한 여러 정책을 설정할 수 있다.

주요 설정 항목은 다음과 같다.

- 암호 복잡성 설정
- 최근 암호 기억
- 암호 사용 기간

### 핵심 정리

```text
암호 정책
→ 암호 복잡성
→ 최근 암호 기억
→ 암호 사용 기간
```

---

## 3. 계정 잠금 정책

잘못된 암호를 일정 횟수 이상 입력했을 경우 사용자 계정을 잠그도록 설정할 수 있다.

```text
계정 잠금 정책
→ 잘못된 암호 입력
→ 계정 잠금
```

---

## 4. 사용자 권한 할당

사용자 권한 할당은 특정 Windows 사용자에게 시스템 관리와 관련된 권한을 부여하는 설정이다.

책에서 제시한 주요 권한은 다음과 같다.

- 감사 및 보안 로그 관리
- 로컬 로그온
- 보안 감사 생성

이 중 **감사 및 보안 로그 관리는 관리자만 수행할 수 있다.**

### 핵심 정리

```text
사용자 권한 할당
→ 감사 및 보안 로그 관리
→ 로컬 로그온
→ 보안 감사 생성

감사 및 보안 로그 관리
→ 관리자만 가능
```

→ 감사 및 보안 로그 관리
→ 로컬 로그온
→ 보안 감사 생성

감사 및 보안 로그 관리
