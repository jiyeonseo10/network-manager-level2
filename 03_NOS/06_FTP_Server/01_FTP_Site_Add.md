# FTP Site Add

네트워크관리사 2급 NOS 파트의 **FTP 사이트 추가** 내용을 정리한다.

---

## 1. FTP 서버 개요

Windows Server에서는 FTP 서버를 구축하여 파일을 업로드하거나 다운로드할 수 있다.

FTP 서버는 **IIS 관리자 프로그램**의 `FTP 사이트 추가` 메뉴를 이용하여 구축한다.

```text
FTP 서버
→ 파일 업로드 / 다운로드
→ IIS 관리자에서 FTP 사이트 추가
```

---

## 2. FTP 사이트 추가

FTP 사이트를 추가할 때 다음 정보를 설정한다.

- FTP 사이트 이름
- FTP 서버 디렉토리

FTP 서버 디렉토리는 FTP 로그인 사용자가 접속할 디렉토리이다.

```text
FTP 사이트 추가
→ FTP 사이트 이름 지정
→ FTP 디렉토리 지정
```

---

## 3. IP 주소 바인딩

IP 주소 바인딩을 이용하면 특정 IP에 대해서만 FTP 서버에 접근할 수 있도록 설정할 수 있다.

특정 IP만 접속하도록 설정하려면 해당 IP 주소를 입력한다.

```text
IP 주소 바인딩
→ 특정 IP만 FTP 서버에 접근 가능
```

---

## 4. FTP 포트 번호

FTP 서버는 명령을 송신 및 수신하기 위해 **21번 포트**를 사용한다.

```text
FTP
→ Port 21
→ 명령 송수신
```

---

## 5. SSL 설정

FTP 서버는 SSL을 이용하여 암호화를 수행할 수 있다.

SSL을 사용하려면 먼저 인증기관으로부터 **SSL 인증서**를 받아야 한다.

SSL 인증서가 없는 경우에는 `SSL 사용 안 함`을 선택한다.

```text
FTP + SSL
→ 암호화 지원
→ SSL 인증서 필요
```

---

## 6. 인증 및 권한 설정

FTP 사이트 생성 과정에서 익명 사용자 접속 허용 여부를 설정할 수 있다.

또한 FTP 디렉토리에 대한 권한을 설정한다.

책에서 제시한 권한은 다음과 같다.

- 읽기
- 쓰기

```text
FTP 인증
→ 익명 사용자 접속 허용 여부 설정

FTP 권한
→ 읽기
→ 쓰기
```

---

## 7. FTP 서버 구축 완료

FTP 사이트 이름, 디렉토리, IP 바인딩, 포트 번호, SSL, 인증 및 권한 설정을 완료하면 FTP 서버 구축이 완료된다.

IIS 관리자에서 등록된 FTP 서버를 확인할 수 있다.
