# FTP Client Usage

네트워크관리사 2급 NOS 파트의 **윈도우에서 FTP 사용하는 방법**을 정리한다.

---

## 1. FTP 클라이언트

개인용 PC에서 FTP 서버에 접속하려면 **FTP 클라이언트 프로그램**을 설치해야 한다.

책에서는 FTP 클라이언트 예시로 **알드라이브**를 사용한다.

```text
FTP 서버 접속
→ FTP 클라이언트 필요

책의 예시
→ 알드라이브
```

---

## 2. FTP 서버 접속 정보

FTP 클라이언트에서 FTP 서버에 연결하려면 다음 정보를 입력한다.

- FTP 서버의 IP 주소
- 아이디
- 비밀번호
- 포트 번호

책의 화면에서는 FTP 포트로 **21번**을 사용한다.

```text
FTP 접속 정보
→ 서버 IP 주소
→ 아이디
→ 비밀번호
→ Port 21
```

---

## 3. FTP 서버 연결

FTP 클라이언트에서 서버 정보와 계정 정보를 입력한 후 연결하면 FTP 서버에 접속할 수 있다.

정상적으로 연결되면 FTP 서버에 있는 파일 및 디렉토리를 확인할 수 있다.

```text
FTP 클라이언트
→ 서버 IP 입력
→ 계정 입력
→ 비밀번호 입력
→ FTP 서버 연결

정상 연결
→ 서버의 파일 / 디렉토리 확인
```

---

## 4. 시험 직전 암기

```text
FTP 서버 접속
→ FTP 클라이언트 필요

책의 FTP 클라이언트
→ 알드라이브

FTP 접속 정보
→ IP 주소
→ 아이디
→ 비밀번호
→ Port 21

정상 연결
→ FTP 서버의 파일 및 디렉토리 확인 가능
```
