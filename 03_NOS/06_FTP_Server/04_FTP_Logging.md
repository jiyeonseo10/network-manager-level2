# FTP Logging

네트워크관리사 2급 NOS 파트의 **FTP 서버 로깅 정보** 내용을 정리한다.

---

## 1. FTP 로깅

IIS 관리자에서 FTP 서버를 선택한 후 **FTP 로깅** 메뉴를 이용하여 FTP 접속 기록을 관리할 수 있다.

FTP 로깅 설정에서는 다음 항목을 지정할 수 있다.

- 로그 파일 이름
- 로그 파일을 저장할 디렉토리 위치
- 로그 파일 생성 주기

책의 예시에서는 로그 파일을 **매일 생성**하도록 설정한다.

```text
FTP 로깅
→ 로그 파일 이름 지정
→ 로그 저장 디렉토리 지정
→ 로그 생성 주기 설정
```

---

## 2. FTP 로그 파일

FTP 서버에 접속한 후 생성된 로그 파일을 확인하면 접속과 관련된 정보를 확인할 수 있다.

책에서 확인할 수 있다고 제시한 정보는 다음과 같다.

- 접속 일자
- 접속 시간
- 접속 IP 주소
- 사용자명
- 실행한 명령

```text
FTP 로그 파일
→ 접속 일자
→ 접속 시간
→ 접속 IP 주소
→ 사용자명
→ 실행 명령
```

---

## 3. FTP 현재 세션

IIS 관리자의 **FTP 현재 세션** 메뉴에서는 현재 FTP 서버에 연결되어 있는 사용자를 확인할 수 있다.

```text
FTP 현재 세션
→ 현재 연결된 FTP 사용자 확인
```

FTP 로그와 현재 세션의 차이는 다음과 같다.

| 구분 | 기능 |
|---|---|
| FTP 로그 | 접속 기록 확인 |
| FTP 현재 세션 | 현재 접속 중인 사용자 확인 |
