# DNS Record

네트워크관리사 2급 NOS 파트의 **DNS 레코드(Record)** 내용을 정리한다.

---

## 1. 호스트 레코드

DNS 서버는 사용자가 입력한 도메인에 대해 어떤 형식의 주소로 응답할지 레코드로 결정한다.

### A 레코드

A 레코드는 호스트 이름에 대해 **IPv4 주소**로 응답하도록 설정하는 레코드이다.

예:

```text
www.boanteam.com
→ IPv4 주소
```

이 경우 호스트 이름은 `www`가 된다.

### AAAA 레코드

AAAA 레코드는 호스트 이름에 대해 **IPv6 주소**로 응답하도록 설정하는 레코드이다.

```text
A
→ IPv4

AAAA
→ IPv6
```

---

## 2. MX 레코드

**MX(Mail Exchanger)** 레코드는 전자우편을 전달하기 위해 사용하는 DNS 레코드이다.

해당 도메인의 메일을 어떤 메일 서버로 전달할지 지정한다.

```text
MX
→ Mail Exchanger
→ 메일 서버 지정
```

---

## 3. PTR 레코드

**PTR(Pointer)** 레코드는 역방향 조회 영역에서 사용한다.

사용자 PC의 IP 주소를 도메인 주소로 변경하기 위해 등록하는 레코드이다.

```text
PTR
→ 역방향 조회 영역에서 사용
→ IP 주소 → 도메인 주소
```

---

## 4. SOA 레코드

**SOA(Start Of Authority)** 레코드는 도메인 영역의 등록 정보를 가지고 있는 기본 레코드이다.

영역이 생성될 때 자동으로 생성되며, 주 영역 DNS와 보조 영역 DNS 간의 동기화에 필요한 정보를 가지고 있다.

### SOA 주요 항목

| 항목 | 설명 |
|---|---|
| 일련번호 | 영역이 변경될 때 증가하는 영역 파일 개정 번호 |
| 주 서버 | 해당 영역의 초기 설정 서버 |
| 책임자 | 영역 관리 책임자의 전자우편 주소 |
| 새로 고침 간격 | 주 영역 DNS와 보조 영역 DNS 사이의 통신 간격 |
| 다시 시도 간격 | 통신 장애 발생 시 다시 시도하는 간격 |
| 만료 | 설정 기간을 초과하면 통신 두절 시 동작 정지 |
| 최소 TTL | 레코드의 캐시 시간 지정 |
| 이 레코드의 TTL | SOA 레코드의 TTL 지정 |

```text
SOA
→ Start Of Authority
→ 영역의 기본 레코드
→ 영역 생성 시 자동 생성
→ Primary / Secondary DNS 동기화 정보
```

---

## 5. CNAME 레코드

CNAME 레코드는 호스트의 **별명(Alias)** 을 등록하는 레코드이다.

같은 IP 주소를 사용하는 여러 호스트를 관리할 때 사용할 수 있다.

```text
CNAME
→ 별명(Alias)
→ 같은 IP를 사용하는 여러 호스트 관리
```

---

## 6. DNS 레코드 비교

| 레코드 | 역할 |
|---|---|
| A | IPv4 주소 등록 |
| AAAA | IPv6 주소 등록 |
| MX | 메일 서버 지정 |
| PTR | IP 주소 → 도메인 주소 |
| SOA | 영역의 기본 정보 및 DNS 동기화 정보 |
| CNAME | 호스트 별명 등록 |

---

```text
PTR
→ 역방향 조회
→ IP → 도메인

SOA

SOA 일련번호

→ 영역 파일 개정 번호

→ 호스트 별명
```
