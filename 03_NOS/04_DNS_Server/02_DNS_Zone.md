# DNS Zone

네트워크관리사 2급 NOS 파트의 **DNS 정방향 영역과 역방향 영역** 내용을 정리한다.

---

## 1. 정방향 영역

정방향 영역(Public Domain Zone)은 DNS 서버에 도메인 주소를 전송하면 해당 도메인의 IP 주소를 응답하는 영역이다.

```text
정방향 영역
→ 도메인 주소를 전송
→ IP 주소 응답
```

DNS 질의(Query)에 대해 어떤 형태의 IP 주소로 응답할지 결정할 수 있으며 IPv4, IPv6 형식을 사용할 수 있다.

윈도우 DNS 관리자에서 정방향 조회 영역을 선택한 후 새 영역을 생성할 수 있다.

```text
DNS 관리자
→ 정방향 조회 영역
→ 새 영역
```

---

## 2. 정방향 영역 생성

새 영역 마법사에서 영역 형식으로 **주 영역**을 선택한다.

영역 이름에는 관리할 도메인 주소를 입력한다.

예:

```text
www.boanteam.com
```

영역 파일은 도메인 주소를 기준으로 자동 생성되며 `.dns` 확장자가 붙는다.

예:

```text
www.boanteam.com
→ www.boanteam.com.dns
```

영역 파일명은 변경할 수도 있다.

정방향 영역 생성 과정에서는 **동적 업데이트 허용 여부**를 설정한다.

```text
정방향 영역 생성
→ 주 영역 선택
→ 도메인 주소 입력
→ 영역 파일 생성
→ 동적 업데이트 설정
```

---

## 3. 역방향 영역

역방향 영역(Inverse Domain Zone)은 사용자 PC에서 IP 주소를 전송하면 DNS 서버가 해당 IP 주소에 대응하는 도메인 주소를 응답하는 영역이다.

```text
역방향 영역
→ IP 주소를 전송
→ 도메인 주소 응답
```

윈도우 DNS 관리자에서 역방향 조회 영역을 선택한 후 새 영역을 생성한다.

```text
DNS 관리자
→ 역방향 조회 영역
→ 새 영역
```

---

## 4. 역방향 영역 생성

새 영역 마법사에서 **주 영역**을 선택한다.

역방향 조회 영역은 IP 주소 형식에 따라 다음 중 하나를 선택할 수 있다.

- IPv4 역방향 조회 영역
- IPv6 역방향 조회 영역

책의 예시에서는 IPv4 역방향 조회 영역을 선택한다.

```text
역방향 조회 영역
→ IPv4 또는 IPv6 선택 가능
```

---

## 5. C Class 기준 네트워크 ID

책에서는 C Class 네트워크를 기준으로 역방향 조회 영역을 생성할 경우 IP 주소의 앞쪽 3개 영역을 입력한다고 설명한다.

예:

```text
10.101.210.x
```

입력:

```text
10.101.210
```

```text
C Class 기준
→ IP 주소 앞 3개 영역 입력
```

---

## 6. 역방향 영역 파일

역방향 영역 파일도 IP 주소를 기준으로 자동 생성되며 `.dns` 확장자가 붙는다.

IPv4 역방향 조회 영역에서는 다음과 같은 형식을 사용한다.

```text
in-addr.arpa
```

예:

```text
10.101.210.in-addr.arpa
```

역방향 영역 생성 과정에서도 동적 업데이트 허용 여부를 설정할 수 있다.

---

## 7. 정방향과 역방향 비교

| 구분 | 정방향 영역 | 역방향 영역 |
|---|---|---|
| 입력 | 도메인 주소 | IP 주소 |
| 출력 | IP 주소 | 도메인 주소 |
| 영역 | Public Domain Zone | Inverse Domain Zone |
| 생성 위치 | 정방향 조회 영역 | 역방향 조회 영역 |
| 영역 파일 | `.dns` | `.dns` |
| 동적 업데이트 | 설정 가능 | 설정 가능 |

```text
정방향
→ 도메인 → IP

역방향
→ IP → 도메인
```

---

## 8. 시험 직전 암기

```text
정방향 영역
→ Public Domain Zone
→ 도메인 → IP

역방향 영역
→ Inverse Domain Zone
→ IP → 도메인

정방향 영역 이름
→ 도메인 주소 입력

영역 파일
→ .dns

역방향 영역
→ IPv4 / IPv6 선택 가능

C Class 기준
→ 앞 3개 옥텟 입력

IPv4 역방향 영역
→ in-addr.arpa

동적 업데이트
→ DNS 정보의 동적 갱신 허용 여부 설정
```
