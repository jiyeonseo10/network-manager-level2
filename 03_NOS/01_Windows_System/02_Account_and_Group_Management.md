# Account and Group Management

네트워크관리사 2급 NOS 파트의 **윈도우 계정 관리와 그룹 관리** 내용을 정리한다.

---

## 1. 윈도우 계정 관리 개요

윈도우 계정 관리는 사용자를 생성하거나 패스워드를 설정하고, 접근 권한을 할당 및 해제하는 작업이다.

### 주요 기능

- 사용자 생성
- 사용자 변경
- 사용자 삭제
- 패스워드 설정
- 접근 권한 할당 및 해제

---

## 2. 윈도우 계정 관리 특징

윈도우 운영체제는 다중 사용자(Multi User)를 지원한다.

사용자 계정은 다음과 같이 분류된다.

- 내장 사용자 계정
- 로컬 사용자 계정
- 도메인 사용자 계정

로컬 사용자 계정은 사용자가 생성한 계정으로 그룹을 통해 관리할 수 있다.

---

## 3. 계정 관리 활동

- 사용자별로 1인 1ID를 할당하고 관리
- 주기적으로 사용자 패스워드 변경
- 사용자 계정에 맞는 권한을 할당하여 통제

### 패스워드 작성 규칙

영문 소문자, 영문 대문자, 숫자, 특수문자 중

- 3가지 이상 조합 → 8자 이상
- 2가지 이상 조합 → 10자 이상

---

## 4. 윈도우 계정의 종류

### 4.1 내장 사용자 계정
Built In User Account

윈도우 운영체제를 설치하면 기본적으로 생성되는 계정이다.

대표 계정:

- Administrator
- Guest
- IUSR_XXX
- IWAM_XXX

#### Administrator

- 자동으로 생성
- 관리자 계정
- 삭제 불가

#### Guest

- 익명의 사용자 접속을 허용할 때 사용
- 관리자가 허락한 자원만 접근 가능

#### IUSR_XXX

- 웹을 이용하여 익명으로 접속
- IIS 서버에서 제공하는 웹 사이트 접속에 사용

#### IWAM_XXX

- IIS 서버의 홈페이지를 실행시킬 때 사용하는 계정

---

## 5. 로컬 사용자 계정

Local User Account

- 윈도우 운영체제로 로그인하는 계정
- 해당 윈도우 운영체제로만 로그인

---

## 6. 도메인 사용자 계정

Domain User Account

윈도우에 로그인할 때 Active Directory에서 관리하는 Domain Controller로 인증받은 후 로그인한다.

### 핵심

- Active Directory 사용
- Domain Controller에서 인증
- Windows Server에 Domain Controller가 설정되어 있어야 함

---

## 7. 그룹 관리 개요

사용자 권한 관리를 위해 그룹을 생성하고 사용자를 해당 그룹으로 묶는다.

그룹에 권한을 부여하거나 해제하여 권한을 관리한다.

---

## 8. 내장형 그룹 종류

| 그룹 | 역할 |
|---|---|
| Administrators | 관리자와 동등한 권한, 시스템 전체 관리 |
| Backup Operators | 파일 및 폴더 백업과 복구 가능 |
| Power Users | 로컬 사용자 계정 생성·수정, 자원 공유 및 중지 가능 |
| Users | 기본적인 권한을 가지는 사용자 그룹 |
| Guests | 관리자가 허락한 자원만 접근 가능 |
| Everyone | 시스템에 접근한 모든 사용자 |

---
