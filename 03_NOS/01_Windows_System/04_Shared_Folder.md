# Shared Folder

네트워크관리사 2급 NOS 파트의 **윈도우 공유 폴더** 내용을 정리한다.

---

## 1. 공유 폴더 만들기

윈도우의 공유 폴더 기능은 자신의 컴퓨터에 있는 폴더를 다른 컴퓨터와 공유할 수 있도록 하는 기능이다.

파일을 함께 공유하면서 업무를 처리할 때 유용하다.

윈도우 탐색기에서 공유할 폴더를 선택한 후 마우스 오른쪽 버튼을 이용하여 공유 폴더를 만들 수 있다.

### 핵심

- 자신의 컴퓨터에 있는 폴더를 다른 컴퓨터와 공유
- 여러 사용자가 파일을 함께 사용할 수 있음
- 윈도우 탐색기에서 공유 설정 가능

---

## 2. 공유 폴더 확인

공유 폴더를 만든 후 정상적으로 생성되었는지 확인할 수 있다.

공유 폴더 목록을 확인할 때는 다음 명령어를 사용한다.

```bash
net share
```

`net share` 명령을 실행하면 현재 시스템에서 공유되고 있는 폴더 목록을 확인할 수 있다.

### 핵심

```text
net share
→ 현재 공유 중인 폴더 목록 확인
```

---

## 3. 공유 폴더 삭제

공유 폴더를 삭제할 때는 `/delete` 옵션을 사용한다.

### 형식

```bash
net share 공유폴더명 /delete
```

### 예시

```bash
net share limbest /delete
```

위 명령은 `limbest` 공유 폴더를 삭제한다.

### 핵심

```text
net share 공유폴더명 /delete
→ 공유 폴더 삭제
```

---

## 4. 윈도우 기본 공유

윈도우 운영체제는 별도로 설정하지 않아도 기본적으로 공유되어 있는 항목이 있다.

대표적인 기본 공유는 다음과 같다.

- `C$`
- `ADMIN$`
- `IPC$`

---

## 5. IPC$

`IPC$`는 네트워크 프로그램 간 통신을 위해 사용한다.

### 주요 특징

- 네트워크 프로그램 간 통신
- 통신을 위해 파이프 사용
- 네트워크 서버 원격 관리에 사용

### 핵심

```text
IPC$
→ 네트워크 프로그램 간 통신
→ 파이프 사용
→ 네트워크 서버 원격 관리
```

---

## 6. 명령어 정리

| 명령어 | 기능 |
|---|---|
| `net share` | 현재 공유 중인 폴더 목록 확인 |
| `net share 공유폴더명 /delete` | 지정한 공유 폴더 삭제 |

---

## 7. 시험 직전 암기

```text

net share
→ 공유 폴더 목록 확인

net share 공유폴더명 /delete
→ 공유 폴더 삭제

윈도우 기본 공유
→ C$
→ ADMIN$
→ IPC$

IPC$
→ 프로그램 간 통신
→ 파이프 사용

```
