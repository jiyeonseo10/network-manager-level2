# Special Permissions

네트워크관리사 2급 NOS 파트의 **리눅스 특수 권한** 내용을 정리한다.

---

## 1. setuid

`setuid`는 실행 파일을 다른 사용자가 실행할 때 **해당 파일의 소유자 권한으로 실행**되도록 하는 특수 권한이다.

책의 대표 예시는 `/usr/bin/passwd`이다.

일반 사용자가 `passwd` 명령을 실행하면 해당 실행 파일이 소유자인 `root` 권한으로 동작한다.

```text
setuid
→ 실행 시 파일 소유자 권한 사용
→ 대표 예: /usr/bin/passwd
```

### 표시 방식

setuid가 설정되면 소유자의 실행 권한 위치에 `s`가 표시된다.

```text
-rwsr-xr-x
```

책의 설명:

```text
s
→ setuid 설정 + 실행 권한 있음

S
→ setuid 설정 + 실행 권한 없음
```

### setuid 설정

setuid의 숫자 값은 `4000`이다.

```bash
chmod 4744 limbest.txt
```

문자 방식으로는 다음과 같이 설정할 수 있다.

```bash
chmod u+s limbest.txt
```

```text
setuid
→ 4000
→ u+s
```

---

## 2. setgid

`setgid`는 파일 생성자의 그룹 소유권과 관련된 특수 권한이다.

특히 디렉토리에 setgid가 설정되어 있으면 해당 디렉토리 아래에서 생성되는 파일이나 디렉토리가 그룹 권한을 이어받도록 사용할 수 있다.

책의 예:

```bash
chmod 2777 AAA
```

여기서 앞의 `2`가 setgid이다.

책에서는 `/var/mail` 디렉토리를 예로 설명한다.

```text
setgid
→ 그룹 권한 관련
→ 디렉토리의 그룹 소유권을 하위에 적용
→ 2000
```

---

## 3. sticky bit

`sticky bit`는 여러 사용자가 함께 사용하는 **공용 디렉토리**에서 사용하는 특수 권한이다.

책의 대표 예시는 `/tmp`이다.

sticky bit가 설정된 디렉토리는 여러 사용자가 사용할 수 있지만, 파일 삭제는 해당 파일의 소유자만 가능하도록 한다.

root 사용자는 예외이다.

```text
sticky bit
→ 공용 디렉토리
→ 모든 사용자 사용 가능
→ 다른 사용자의 파일 삭제 제한
→ root는 예외
```

### 숫자 값

sticky bit의 숫자 값은 `1000`이다.

### 표시 방식

sticky bit는 실행 권한 위치에 `t`로 표시된다.

```text
drwxrwxrwt
```

대표 디렉토리:

```text
/tmp
```

---

## 4. 특수 권한 비교

| 특수 권한 | 숫자 값 | 핵심 역할 |
|---|---:|---|
| setuid | 4000 | 실행 시 파일 소유자 권한 사용 |
| setgid | 2000 | 그룹 권한 관련, 그룹 소유권 적용 |
| sticky bit | 1000 | 공용 디렉토리에서 다른 사용자 파일 삭제 제한 |

```text
setuid
→ 4000
→ 소유자 권한

setgid
→ 2000
→ 그룹 권한

sticky bit
→ 1000
→ 삭제 제한
```

---

## 5. setuid 실행 표시

```text
s
→ 실행 권한 있음

S
→ 실행 권한 없음
```

책에서는 실행 파일에 setuid를 설정했을 때 소문자 `s`이면 정상적으로 실행할 수 있고, 대문자 `S`이면 실행할 수 없다고 설명한다.

---

## 6. 시험 직전 암기

```text
setuid
→ 4000
→ u+s
→ 파일 소유자 권한으로 실행
→ /usr/bin/passwd
→ 소유자 실행 위치에 s

s
→ 실행 권한 있음

S
→ 실행 권한 없음

setgid
→ 2000
→ 그룹 권한 관련
→ 하위 파일 / 디렉토리에 그룹 소유권 적용

sticky bit
→ 1000
→ 공용 디렉토리
→ /tmp
→ 다른 사용자의 파일 삭제 제한
→ t로 표시

특수 권한 숫자
→ setuid = 4000
→ setgid = 2000
→ sticky bit = 1000
```
