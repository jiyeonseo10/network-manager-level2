# RPM Package

네트워크관리사 2급 NOS 파트의 **RPM 패키지 관리** 내용을 정리한다.

---

## 1. RPM 개요

RPM은 **Redhat Package Manager**의 약자이다.

프로그램을 설치하기 위해 사용하는 패키지 관리 도구이며, 확장자가 `.rpm`인 패키지 파일을 사용한다.

```text
RPM
→ Redhat Package Manager
→ .rpm 패키지 관리
```

---

## 2. rpm 기본 옵션

| 옵션 | 설명 |
|---|---|
| `-i` | 패키지 설치 |
| `-v` | 설치 과정 확인 |
| `-h` | 설치 진행 과정을 `#` 마크로 화면에 출력 |
| `-U` | 패키지 업그레이드 |
| `-e` | 패키지 삭제 |
| `-qa` | 설치된 모든 패키지 확인 |
| `-qc` | 패키지에 의해 설치된 파일 중 설정 파일 경로 출력 |
| `-qd` | 패키지에 의해 설치된 파일 중 문서 파일 경로 출력 |
| `-qi` | 설치된 패키지 정보 확인 |
| `-ql` | 특정 패키지로 어떤 파일이 설치되었는지 확인 |
| `-qs` | 패키지로 설치된 파일 정상 여부 확인 |
| `-qpl` | 패키지 파일에 어떤 파일이 포함되었는지 확인 |
| `-V` | 패키지 검사 |

```text
-i
→ 설치

-v
→ 설치 과정 확인

-h
→ #으로 진행 과정 출력

-U
→ 업그레이드

-e
→ 삭제

-qa
→ 설치된 모든 패키지 확인

-qc
→ 설정 파일 경로

-qd
→ 문서 파일 경로

-qi
→ 패키지 정보

-ql
→ 설치된 파일 목록

-qs
→ 설치 파일 정상 여부 확인

-qpl
→ 패키지 파일 안의 파일 목록

-V
→ 패키지 검사
```

## 3. 설치된 모든 패키지 확인

```bash
rpm -qa
```

설치되어 있는 모든 패키지를 확인한다.

```text
rpm -qa
→ 설치된 모든 패키지 확인
```

---

## 4. 패키지 검증

`rpm -V` 옵션은 패키지를 검사하는 옵션이다.

패키지가 임의로 변경되었는지, 파일 크기, 심볼릭 링크, 장치 파일 변경 등을 확인한다.

### rpm 검증 코드

| 검증 코드 | 설명 |
|---|---|
| `5` | MD5 체크섬 변경 |
| `S` | 파일 크기 변경 |
| `L` | 심볼릭 링크 변경 |
| `D` | 장치 파일 변경 |
| `U` | 파일 사용자, 소유자 변경 |
| `G` | 파일 그룹 변경 |
| `M` | 파일 모드 변경 |
| `?` | 원인을 알 수 없거나 예측하지 못한 결과 |

```text
5
→ MD5

S
→ Size

L
→ Symbolic Link

D
→ Device

U
→ User / Owner

G
→ Group

M
→ Mode

?
→ 원인 불명
```

## 5. RPM 추가 옵션

| 옵션 | 설명 |
|---|---|
| `--test` | 패키지 설치 시 가능한 문제점 점검 |
| `--force` | 설치를 강제적으로 진행 |
| `--nodeps` | 패키지 설치·삭제 시 의존성을 무시하고 진행 |

```text
--test
→ 설치 전 문제점 점검

--force
→ 강제 설치

--nodeps
→ 의존성 무시
```

## 6. queryformat 사용

책에서는 `--queryformat`을 사용하여 설치된 패키지의 정보를 원하는 형식으로 확인하는 방법을 설명한다.

예:

```bash
rpm -qa --queryformat "%{NAME} : %{Summary}\n"
```

각 패키지의 이름과 설명을 출력한다.

또한 설치일을 확인할 수도 있다.

```text
rpm -qa --qf ...
→ 설치일 확인 가능
```

설치 용량도 확인할 수 있다.

```bash
rpm -qa --queryformat '%{NAME} %{SIZE}\n'
```

```text
--queryformat
→ 패키지 출력 형식 지정
```

```text
→ 설정 파일

rpm -qd
→ 문서 파일

→ rpm 파일 안의 파일 목록

```
