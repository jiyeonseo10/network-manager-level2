# Text Commands

네트워크관리사 2급 NOS 파트의 **리눅스 텍스트 명령어 `cat`, `grep`** 내용을 정리한다.

---

## 1. cat

`cat` 명령어는 파일의 내용을 확인할 수 있는 명령어이다.

기본 형식:

```bash
cat [옵션] 파일명
```

예:

```bash
cat /etc/passwd
```

`/etc/passwd` 파일의 내용을 화면에 출력한다.

### cat -n

```bash
cat -n /etc/passwd
```

파일 내용을 출력할 때 **행 번호를 함께 출력**한다.

```text
cat
→ 파일 내용 확인

cat -n
→ 행 번호와 함께 출력
```

---

## 2. cat과 리다이렉션

`cat` 명령어는 리다이렉트를 함께 사용하여 파일을 복사하거나 출력 결과를 파일에 저장할 수 있다.

예:

```bash
cat /etc/passwd > test
```

`/etc/passwd`의 내용을 `test` 파일에 저장한다.

또한 다음과 같이 사용할 수 있다.

```bash
cat > test200
```

키보드로 입력한 내용을 `test200` 파일에 저장한다.

```text
>
→ 출력 방향을 파일로 변경
→ 출력 결과를 파일에 저장
```

---

## 3. grep

`grep` 명령어는 특정 파일 안에 있는 문자열을 검색하는 명령어이다.

기본 형식:

```bash
grep [검색 문자열] [파일명]
```

또는:

```bash
grep [옵션] [검색 문자열] [파일명]
```

```text
grep
→ 파일 내부 문자열 검색
```

---

## 4. grep 옵션

| 옵션 | 설명 |
|---|---|
| `-c` | 검색 문자열이 속한 행의 수 출력 |
| `-H` | 파일명과 함께 출력 |
| `-i` | 대소문자를 구분하지 않음 |
| `-n` | 검색한 문자가 속한 행 번호와 함께 출력 |
| `-r` | 현재 경로에서 하위 경로까지 검색 |
| `-v` | 검색하는 문자가 없는 행 출력 |
| `-w` | 패턴 표현식을 하나의 단어로 검색 |

```text
-c
→ 검색된 행의 수

-H
→ 파일명과 함께 출력

-i
→ 대소문자 구분 안 함

-n
→ 행 번호와 함께 출력

-r
→ 하위 디렉토리까지 검색

-v
→ 검색 문자열이 없는 행 출력

-w
→ 하나의 단어 단위로 검색
```

---

## 5. grep 사용 예

```bash
grep -c 키보드 test200
```

`test200` 파일에서 `키보드`라는 문자열이 있는 **행의 수**를 출력한다.

```bash
grep -H 키보드 test200
```

파일명과 검색 결과를 함께 출력한다.

```bash
grep -r aaa .
```

현재 디렉토리부터 하위 디렉토리까지 `aaa` 문자열을 검색한다.

---

## 6. grep 정규식

`grep`에서는 정규식(Regular Expressions)을 사용할 수 있다.

책에서 제시한 정규식은 다음과 같다.

| 표현 | 의미 |
|---|---|
| `.` | 한 글자를 의미 |
| `*` | 길이와 관계없는 문자열 |
| `^` | 행의 첫 시작 |
| `$` | 행의 마지막 위치 |
| `[]` | 한 문자 길이 패턴 |
| `[^]` | 입력된 문자들을 제외 |

```text
.
→ 한 글자

*
→ 길이와 관계없는 문자열

^
→ 행의 시작

$
→ 행의 끝

[]
→ 한 문자 길이 패턴

[^]
→ 입력된 문자 제외
```
