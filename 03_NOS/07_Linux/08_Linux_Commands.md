# Linux Commands

네트워크관리사 2급 NOS 파트의 **리눅스 기본 명령어** 내용을 정리한다.

---

## 1. mkdir

`mkdir`는 디렉토리를 생성하는 명령어이다.

`Make Directory`의 약자로, 리눅스에서 새로운 디렉토리를 만들 때 사용한다.

예:

```bash
mkdir boangisa
```

```text
mkdir
→ 디렉토리 생성
```

### mkdir 옵션

| 옵션 | 설명 |
|---|---|
| `-m` | 디렉토리 생성 시 권한 지정 |
| `-p` | 상위 경로도 함께 생성 |
| `-v` | 디렉토리 생성 후 메시지 출력 |

예:

```bash
mkdir -m 777 boanteam
```

```text
-m
→ 생성과 동시에 권한 지정

-p
→ 상위 경로도 함께 생성

-v
→ 생성 메시지 출력
```

---

## 2. cp

`cp(copy)`는 파일이나 디렉토리를 복사하는 명령어이다.

형식:

```bash
cp [옵션] 원본파일 대상파일
```

예:

```bash
cp test test2
```

`test` 파일을 `test2` 파일로 복사한다.

### cp 옵션

| 옵션 | 설명 |
|---|---|
| `-f` | 덮어쓰기를 하여 복사 |
| `-r` | 하위 디렉토리 전체를 모두 복사 |

```text
cp
→ 파일 / 디렉토리 복사

-f
→ 덮어쓰기

-r
→ 하위 디렉토리 전체 복사
```

---

## 3. rm

`rm(remove)`은 파일을 삭제하는 명령어이다.

예:

```bash
rm limbest2.txt
```

```text
rm
→ 파일 삭제
```

### rm 옵션

| 옵션 | 설명 |
|---|---|
| `-f` | 묻지 않고 강제로 삭제 |
| `-r` | 디렉토리 삭제 시 파일과 하위 경로 모두 삭제 |
| `-v` | 파일 삭제 정보를 출력 |

예:

```bash
rm -r boanteam
```

```text
rm -f
→ 확인 없이 강제 삭제

rm -r
→ 디렉토리와 하위 내용 모두 삭제

rm -v
→ 삭제 정보 출력
```

---

## 4. mv

`mv(move)`는 파일이나 디렉토리를 이동하거나 파일 이름을 변경할 때 사용하는 명령어이다.

형식:

```bash
mv [옵션] 원본파일 대상파일
```

같은 디렉토리에서 다른 파일명을 지정하면 이름을 변경하는 역할을 한다.

예:

```bash
mv limbest.txt boangisa.txt
```

```text
mv
→ 파일 / 디렉토리 이동
→ 파일 이름 변경
```

---

## 5. mv 옵션

| 옵션 | 설명 |
|---|---|
| `-b` | 백업 파일 생성 |
| `-f` | 사용자에게 묻지 않고 파일 덮어쓰기 |
| `-i` | 덮어쓸 경우 사용자에게 물어봄 |
| `-n` | 파일이 존재하면 덮어쓰지 않음 |
| `-S` | 지정한 접미사로 백업 생성 |
| `-t` | 전체 원본 파일을 대상 디렉토리로 이동 |
| `-u` | 파일이 업데이트된 경우에만 이동 |
| `-v` | 진행 상태 정보 출력 |

```text
mv -b
→ 백업 파일 생성

mv -f
→ 확인 없이 덮어쓰기

mv -i
→ 덮어쓰기 전 확인

mv -n
→ 기존 파일이 있으면 덮어쓰지 않음

mv -u
→ 업데이트된 경우만 이동

mv -v
→ 진행 상태 출력
```

---

## 6. 명령어 비교

| 명령어 | 기능 |
|---|---|
| `mkdir` | 디렉토리 생성 |
| `cp` | 파일/디렉토리 복사 |
| `rm` | 파일/디렉토리 삭제 |
| `mv` | 파일/디렉토리 이동 또는 이름 변경 |
