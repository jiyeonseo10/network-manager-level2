# Vi Editor

네트워크관리사 2급 NOS 파트의 **vi 편집기** 내용을 정리한다.

---

## 1. vi 편집기 개요

`vi`는 문서를 편집할 수 있는 에디터이다.

vi는 크게 다음 두 모드로 나뉜다.

```text
명령 실행 모드
→ 저장, 종료, 이동, 삭제 등의 명령 실행

입력 모드
→ 문서 내용 입력
```

입력 모드로 전환할 때는 `i`, `a`, `o` 등을 사용한다.

입력 모드에서 다시 명령 실행 모드로 돌아갈 때는 `ESC` 키를 사용한다.

```text
i / a / o
→ 입력 모드

ESC
→ 명령 실행 모드
```

명령 실행 모드에서 `:`를 입력하면 저장이나 종료 등의 명령을 실행할 수 있다.

---

## 2. vi 입력 모드

| 명령 | 설명 |
|---|---|
| `i` | 커서 위치에서 입력 모드로 변경 |
| `a` | 커서 위치 우측 한 칸에서 입력 모드로 변경 |
| `o` | 커서 바로 아래에 줄을 만들고 입력 |

추가 편집 명령:

| 명령 | 설명 |
|---|---|
| `i` | 커서 앞에서 입력 |
| `a` | 커서 뒤에서 입력 |
| `I` | 현재 행의 처음에서 입력 |
| `A` | 현재 행의 마지막에서 입력 |
| `o` | 현재 행 아래에 새로운 행 입력 |
| `O` | 현재 행 위에 새로운 행 입력 |

```text
i / a
→ 커서 앞 / 뒤

I / A
→ 현재 행 처음 / 마지막

o / O
→ 현재 행 아래 / 위에 새 행
```

---

## 3. vi 저장 명령어

| 명령어 | 설명 |
|---|---|
| `:w` | 파일 저장 |
| `:w!` | 무조건 파일 저장 |
| `:30,60w newfile` | 30행부터 60행까지 newfile로 저장 |
| `:30,60w>>file` | 30행부터 60행까지 지정 파일에 추가 |
| `:w %.new` | 현재 파일명을 이용하여 `.new` 파일로 저장 |
| `Q` | vi 종료 후 ex로 전환 |
| `:e file1` | vi를 종료하지 않고 file1 편집 |
| `:r newfile` | newfile 내용을 현재 파일에 읽어옴 |
| `:n` | 현재 파일 편집 |
| `:e!` | 현재 파일을 마지막 저장 상태로 되돌림 |
| `:e#` | 파일을 번갈아 가며 편집 |
| `:vi` | ex에서 vi 호출 |

저장 후 종료:

```text
:wq
→ 저장하고 종료
```

## 4. vi 이동 명령어

기본 방향 이동:

```text
h → 왼쪽
j → 아래
k → 위
l → 오른쪽
```

단어 이동:

```text
w
→ 다음 단어 방향으로 이동

b
→ 이전 단어 방향으로 이동

e
→ 단어 끝으로 이동
```

행 이동:

```text
0
→ 현재 행의 처음

$
→ 현재 행의 끝
```

화면 이동:

```text
H
→ 화면 맨 위 행

M
→ 화면 중간 행

L
→ 화면 맨 아래 행
```

책에 나온 기타 이동 명령:

| 명령어 | 설명 |
|---|---|
| `)` / `(` | 다음 문장 / 전 문장 처음으로 이동 |
| `}` / `{` | 다음 문단 / 전 문단 처음으로 이동 |
| `]]` / `[[` | 다음 절 / 전 절 시작으로 이동 |
| `Enter` | 다음 행의 공백이 아닌 처음으로 이동 |
| `^` | 현재 행의 공백이 아닌 처음으로 이동 |
| `+`, `-` | 다음 행 / 이전 행의 공백이 아닌 처음으로 이동 |
| `n|` | 현재 행의 n번째 열로 이동 |
| `nH` | 화면 위쪽에서 n번째 행 |
| `nL` | 화면 아래쪽에서 n번째 행 |
| `+F`, `+B` | 한 화면 다음 / 이전 |
| `+D`, `+U` | 반 화면 아래 / 위 |
| `+E`, `+Y` | 화면 한 행 위 / 아래 |
| `z` | 커서 행을 화면 맨 위로 |
| `z.` | 커서 행을 화면 중간으로 |
| `z-` | 커서 행을 화면 맨 아래로 |
| `+L` | 스크롤 없이 화면 리로드 |

## 5. vi 삭제 및 삽입 명령어

| 명령어 | 설명 |
|---|---|
| `x` | 커서가 위치한 문자 삭제 |
| `X` | 커서 앞 문자 삭제 |
| `dw` | 단어 삭제 |
| `dd` | 현재 행 삭제 |
| `dmotion` | 커서와 motion 대상 사이 텍스트 삭제 |
| `D` | 커서 위치부터 현재 행 끝까지 삭제 |
| `p` | 지운 텍스트를 커서 오른쪽에 삽입 |
| `P` | 지운 텍스트를 커서 왼쪽에 삽입 |

```text
x
→ 현재 문자 삭제

X
→ 앞 문자 삭제

dw
→ 단어 삭제

dd
→ 현재 행 삭제

D
→ 커서부터 행 끝까지 삭제

p / P
→ 지운 텍스트 삽입
```

## 6. vi 문자열 검색

| 명령어 | 설명 |
|---|---|
| `/검색문자열/` | 현재 위치에서 아래 방향 검색 |
| `?검색문자열?` | 현재 위치에서 위 방향 검색 |
| `n` | 찾은 문자열 다음으로 계속 검색 |
| `N` | 찾은 문자열 이전으로 계속 검색 |

```text
/
→ 아래 방향 검색

?
→ 위 방향 검색

n
→ 같은 방향으로 계속 검색

N
→ 반대 방향으로 계속 검색
```

## 7. vi 명령행 옵션

| 명령 | 설명 |
|---|---|
| `vi 파일명` | 지정 파일 열기 |
| `vi 파일명1 파일명2` | 파일1, 파일2 순서대로 열기 |
| `vi -r 파일명` | 파일 복구 후 편집 |
| `vi -t 태그` | 태그 검색 후 지정 위치부터 편집 |
| `vi +파일명` | 파일을 열고 본문 마지막 행에 위치 |
| `vi +n 파일명` | 파일을 열고 커서를 n행에 위치 |
| `vi -c Command 파일` | 파일을 열고 지정 명령 실행 |
| `vi +/패턴 파일` | 패턴 위치에서 파일 열기 |

```text
vi -r
→ 복구 후 편집

vi +n
→ n번째 행에서 시작

vi +/패턴
→ 패턴 위치에서 시작
```

## 8. vi 설정

vi는 `.exrc` 설정 파일을 사용하여 환경 설정을 할 수 있다.

예:

```text
set number
set tabstop=8
```

### set 설정 값

| 설정 | 설명 |
|---|---|
| `autoindent` | 자동 들여쓰기 설정 |
| `shiftwidth` | 자동 들여쓰기 여백 값 |
| `number` | 화면에 라인 번호 표시 |
| `tabstop` | 탭 간격 설정 |
| `showmode` | 삽입 모드 표시 여부 |
| `wrapmargin` | 오른쪽 여백 설정 |

---

## 9. vi set 옵션

| 옵션 | 설명 |
|---|---|
| `:set ai` | 윗라인과 동일하게 자동 들여쓰기 |
| `:set si` | if, for 등을 입력하고 다음 라인 이동 시 자동 들여쓰기 |
| `:set paste` | 붙여넣기 시 계단 현상 방지 |
| `:set ts=4` | TAB 간격 설정 |
| `:set sw=4` | 들여쓰기 깊이 설정 |
| `:set et` | TAB 입력 시 해당 공간만큼 SPACE 이동 |
| `:set encoding=utf8` | 기본 인코딩 설정 |
| `:set fenc=utf8` | 다른 인코딩으로 저장 |
| `:set t_ti` | 터미널에서 vi 종료 시 화면 내용을 남게 함 |
| `:set ruler` | 우측 하단에 라인 및 칼럼 위치 표시 |
| `:set ff=unix` | 라인 변경 문자 변경 |
| `:set ff=passwd` | 문서 암호화 |
| `:set ic` | 검색 패턴 사용 시 대소문자 구분 안 함 |
| `:set wam` | 종료 시 경고 메시지 출력 |

줄 번호 출력:

```text
:set nu
→ 문서에 줄 번호 표시
```
