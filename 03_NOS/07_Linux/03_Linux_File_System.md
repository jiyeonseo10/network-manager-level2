# Linux File System

네트워크관리사 2급 NOS 파트의 **리눅스 파일 시스템 관리 명령어**를 정리한다.

---

## 1. fdisk

`fdisk`는 하드디스크를 초기화하고 파티션을 생성하거나 관리할 때 사용하는 명령어이다.

기본 형식은 다음과 같다.

```bash
fdisk [옵션] [장치명]
```

책에서 제시한 주요 옵션은 다음과 같다.

| 옵션 | 설명 |
|---|---|
| `-l` | 파티션 정보 확인 |
| `-v` | 버전 정보 출력 |
| `-s 장치명` | 지정한 장치의 크기 출력 |
| `-d` | 파티션 삭제 |
| `-n` | 새로운 파티션 생성 |
| `-p` | 현재 파티션 설정 상태 확인 |

```text
fdisk
→ 하드디스크 파티션 관리

-n
→ 새 파티션 생성

-d
→ 파티션 삭제

-p
→ 파티션 정보 확인
```

## 2. mkfs

파티션을 생성한 후에는 파일 시스템을 만들어야 한다.

이때 사용하는 명령어가 `mkfs`이다.

```bash
mkfs [옵션] [장치이름]
```

책에서 제시한 주요 옵션은 다음과 같다.

| 옵션 | 설명 |
|---|---|
| `-V` | 실행되는 파일 시스템 명령어 등의 정보 출력 |
| `-t` | 파일 시스템 형식 지정 |
| `-c` | Bad Block 검사 |
| `-l` | 파일에서 Bad Block 정보 읽기 |
| `-v` | 진행 사항 출력 |

예:

```bash
mkfs -t ext4 /dev/sdb1
```

`/dev/sdb1`에 ext4 파일 시스템을 생성한다.

`mke2fs`는 ext2, ext3, ext4 파일 시스템을 생성할 때 사용할 수 있다.

```text
mkfs
→ 파일 시스템 생성

-t
→ 파일 시스템 형식 지정

mke2fs
→ ext2 / ext3 / ext4 생성
```

## 3. fsck

`fsck`는 파일 시스템의 무결성을 검사하는 명령어이다.

파일 시스템에 오류가 있는지 검사하고 필요에 따라 수정할 수 있다.

```text
fsck
→ 파일 시스템 무결성 검사
→ 파일 시스템 오류 검사 및 수정
```

책에서 제시한 `fsck` 옵션은 다음과 같다.

| 옵션 | 설명 |
|---|---|
| `-s` | 여러 파일 시스템을 점검할 때 직렬화하여 검사 |
| `-t` | 검사할 파일 시스템 지정 |
| `-A` | `/etc/fstab`에 기록된 파일 시스템 모두 검사 |
| `-N` | 실제 검사는 하지 않고 수행될 내용 출력 |
| `-P` | 병렬 처리하여 루트 파일 시스템 점검 |
| `-R` | 루트 파일 시스템 제외 |
| `-V` | 세부 내용 출력 |

파일 시스템 검사와 관련된 옵션은 다음과 같다.

| 옵션 | 설명 |
|---|---|
| `-a` | 무결성 검사 후 자동 검사 수행 |
| `-r` | 대화형 모드로 오류 수정 |
| `-n` | 오류를 수정하지 않고 출력 |
| `-y` | 오류 자동 수정 |

```text
fsck
→ 파일 시스템 검사

-A
→ /etc/fstab에 기록된 파일 시스템 모두 검사

-R
→ Root 파일 시스템 제외

-n
→ 오류 수정 안 함

-y
→ 오류 자동 수정
```

## 4. mount

`mount`는 파일 시스템이나 장치를 특정 디렉토리에 연결하여 사용할 수 있도록 하는 명령어이다.

CD-ROM, USB 등의 장치를 사용할 때도 마운트를 수행한다.

예:

```bash
mount /dev/cdrom /mnt/cdrom
```

`mount` 명령만 실행하면 현재 연결된 파일 시스템 목록을 확인할 수 있다.

책에서 제시한 주요 옵션은 다음과 같다.

| 옵션 | 설명 |
|---|---|
| `-v` | 자세한 정보 출력 |
| `-f` | 마운트 가능 여부 점검 |
| `-n` | `/etc/mtab`에 기록하지 않고 마운트 |
| `-r` | 읽기 전용으로 마운트 |
| `-w` | 읽기 및 쓰기 모드로 마운트 |
| `-t fstype` | 파일 시스템 유형 지정 |

```text
mount
→ 파일 시스템 / 장치를 디렉토리에 연결

-r
→ Read Only

-w
→ Read / Write

-t
→ 파일 시스템 형식 지정
```

## 5. /etc/fstab

`/etc/fstab`은 mount를 수행할 때 참조하는 파일이다.

파일 시스템 마운트와 관련된 정보를 저장한다.

책에서 제시한 필드는 다음과 같다.

```text
1. 파일 시스템 장치
2. 마운트 포인트
3. 파일 시스템 형식
4. 옵션
5. 파일 점검 옵션
```

주요 옵션은 다음과 같다.

| 옵션 | 설명 |
|---|---|
| `default` | 일반적인 파일 시스템 |
| `auto` | 부팅 시 자동으로 마운트 |
| `exec` | 실행 파일 실행 허용 |
| `suid` | setuid와 setgid 허용 |
| `ro` | 읽기 전용 |
| `rw` | 읽기/쓰기 가능 |
| `user` | 일반 사용자도 마운트 가능 |
| `nouser` | root만 마운트 가능 |
| `noauto` | 부팅 시 자동 마운트하지 않음 |
| `noexec` | 실행 파일 실행 불가 |
| `nosuid` | setuid와 setgid 허용하지 않음 |
| `usrquota` | 사용자별 Quota 설정 |
| `grpquota` | 그룹별 Quota 설정 |

### Dump

```text
0
→ dump 실행 안 함

1
→ 백업을 위한 dump 가능
```

### 파일 점검 옵션

```text
0
→ 부팅 시 fsck 실행 안 함

1
→ Root 파일 시스템

2
→ Root 파일 시스템을 제외한 나머지 파일 시스템
```

## 6. umount

`umount`는 마운트된 파일 시스템을 해제하는 명령어이다.

예:

```bash
umount /mnt/cdrom
```

책에서 제시한 옵션은 다음과 같다.

| 옵션 | 설명 |
|---|---|
| `-n` | `/etc/mtab`을 변경하지 않고 마운트 해제 |
| `-v` | 정보 출력 |
| `-a` | `/etc/mtab`에 지정된 파일 시스템 모두 해제 |
| `-t 파일시스템명` | 지정된 파일 시스템 해제 |

```text
umount
→ 마운트 해제
```

---

## 7. eject

CD-ROM 등의 장치를 꺼낼 때 사용하는 명령어이다.

책의 실행 흐름은 다음과 같다.

```bash
mount /dev/cdrom /mnt/cdrom
umount /mnt/cdrom
eject
```

```text
mount
→ CD-ROM 마운트

umount
→ 마운트 해제

eject
→ CD 꺼내기
```
