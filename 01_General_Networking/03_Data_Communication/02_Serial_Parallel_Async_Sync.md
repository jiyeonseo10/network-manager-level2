# 직렬/병렬 전송과 비동기/동기 전송

## 1. 직렬 전송(Serial Transmission)

한 문자의 Bit를 하나의 전송선을 통해 순차적으로 전송하는 방식이다.

```text
Serial
→ 하나의 전송로
→ Bit를 순차적으로 전송
```

### 특징

```text
동기식 전송 방식
```

### 장점

```text
전송 에러가 적음
장거리 전송에 적합
통신 회선 비용이 저렴
```

### 단점

```text
전송 속도가 느림
```

---

## 2. 병렬 전송(Parallel Transmission)

한 문자의 Bit들을 각각의 전송로를 통해 한꺼번에 전송하는 방식이다.

```text
Parallel
→ 여러 전송로
→ 동시에 전송
```

### 특징

```text
송수신기 단순
```

### 장점

```text
Data를 빠르게 전송
```

### 단점

```text
여러 회선 필요
전송 비용 증가
Error 발생 가능성 높음
```

---

# 3. 직렬 전송 vs 병렬 전송

| 구분 | 직렬 전송 | 병렬 전송 |
|---|---|---|
| 전송로 | 하나 | 여러 개 |
| 전송 | 순차 전송 | 동시에 전송 |
| 특징 | 동기식 전송 방식 | 송수신기 단순 |
| 장점 | Error 적음, 장거리, 저비용 | 빠른 전송 |
| 단점 | 느림 | Error 가능성 높음 |

핵심:

```text
직렬
→ 한 줄
→ 순차
→ 느리지만 장거리/저비용

병렬
→ 여러 줄
→ 동시에
→ 빠르지만 비용 증가
```

---

# 4. 비동기식 전송(Asynchronous Transmission)

한 번에 한 문자씩 전송하는 방식이다.

```text
Asynchronous
→ 한 문자씩 전송
```

문자를 전송할 때:

```text
Start Bit
Stop Bit
```

를 사용한다.

또한 문자와 문자 사이에는 유휴 시간이 존재한다.

### 전송 단위

```text
문자 단위의 Bit Block
```

### 전송 속도

```text
저속
```

### 전송 효율

```text
낮음
```

### 장점

```text
동기화가 단순
저렴
```

### 단점

```text
문자 사이 유휴 시간 발생
```

---

# 5. 동기식 전송(Synchronous Transmission)

Data를 Block으로 나누어 Block 단위로 전송하는 방식이다.

```text
Synchronous
→ Data를 Block으로 나눔
→ Block 단위 전송
```

많은 양의 Data를 전송하는 데 유리하다.

### 전송 단위

```text
Frame
```

### 전송 속도

```text
고속
```

### 전송 효율

```text
높음
```

### 장점

```text
원거리 전송이 용이
```

### 단점

```text
고가
```

---

# 6. 비동기식 vs 동기식

| 구분 | 비동기식 | 동기식 |
|---|---|---|
| 개념 | 한 문자씩 전송 | Block 단위 전송 |
| 전송 단위 | 문자 단위 Bit Block | Frame |
| 속도 | 저속 | 고속 |
| 효율 | 낮음 | 높음 |
| 장점 | 동기화 단순, 저렴 | 원거리 전송 용이 |
| 단점 | 문자 사이 유휴 시간 | 고가 |

---

# 7. 혼합형 동기식 전송

교재 기준:

```text
혼합형 동기식 전송
→ 동기식 특징 + 비동기식 특징
→ 비동기식보다 빠름
```

# 시험 직전 암기

```text
Serial
→ 하나의 회선
→ 순차 전송
→ 장거리
→ 저비용
→ 느림
```

```text
Parallel
→ 여러 회선
→ 동시 전송
→ 빠름
→ 비용 증가
```

```text
Asynchronous
→ 한 문자씩
→ Start Bit / Stop Bit
→ 문자 사이 유휴 시간
→ 저속
→ 효율 낮음
```

```text
Synchronous
→ Block 단위
→ Frame
→ 고속
→ 효율 높음
```

## 자주 헷갈리는 부분

```text
직렬 vs 병렬
→ 전송선 개수 차이
```

```text
비동기 vs 동기
→ Data를 어떤 단위로 보내는지 차이
```

```text
비동기
→ 문자 단위
→ Start / Stop Bit

동기
→ Block 단위
→ Frame
```
